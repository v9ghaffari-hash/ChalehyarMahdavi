گزارش رفع شکست ساخت نسخه ۴۲

گزارش GitHub Actions که همراه درخواست ارسال شد، مراحل checkout، نصب JDK 17، Android SDK، Gradle 8.11.1 و taskهای آماده‌سازی/بسته‌بندی را با موفقیت گذرانده بود. شکست دقیقاً در task کامپایل Kotlin رخ داده بود:

MainActivity.kt:748:58 Unresolved reference 'TopLeft'

در Jetpack Compose مقدار Alignment.TopLeft وجود ندارد. این مقدار در نسخه ۴۳ به Alignment.TopStart اصلاح شده است. این تنها diagnostic کامپایل Kotlin در فایل گزارش‌شده بود.

همچنین شناسه برنامه برای نصب مستقل به ir.chillehyar.qadamyar.v43 تغییر کرده و versionCode برابر 43 است.

وضعیت تأیید: فایل ZIP و XMLها بررسی شده‌اند و خطای ثبت‌شده در سورس رفع شده است. به‌علت نبود Android SDK و Gradle در محیط فعلی، اجرای build نهایی محلی انجام نشد؛ تأیید نهایی APK باید با اجرای GitHub Actions نسخه ۴۳ انجام شود.
