قدم یار — نسخهٔ ۵۰

این پروژه سورس کامل اپلیکیشن اندروید «قدم یار» بر پایهٔ Kotlin و Jetpack Compose است.
شناسهٔ برنامه: ir.chillehyar.qadamyar.v49
نسخه: 50.0-qadam-yar (versionCode=50)

این نسخه به‌روزرسانی V49 است و همان شناسهٔ نصب V49 را نگه می‌دارد؛ بنابراین روی نصب قبلی V49 به‌صورت به‌روزرسانی نصب می‌شود و داده‌های محلی برنامه با حذف و نصب تازه جایگزین نمی‌شوند.

تغییرات این نسخه:
- تصویر هدر ارسالی کاربر جایگزین تصویر قبلی شده است؛ نسبت افقی تصویر حفظ شده و نوشتهٔ «قدم یار» و زیرنویس داخل خود تصویر قرار دارند.
- دکمه‌های زنگوله و تنظیمات از روی هدر برداشته شده‌اند.
- پایین هدر و بالای کارت چله به هم متصل شده‌اند؛ لبهٔ بالایی کارت چله صاف است و گوشه‌های بالای هدر گرد باقی مانده‌اند. بالای تصویر نیز یک فید بسیار ملایم دارد.
- دو میانبر شناور روی هدر اضافه شده‌اند: «تاکتیک‌های شیطان» در سمت چپ و «جدول الف» به رنگ طلایی در سمت راست. روی دکمهٔ جدول الف هر پنج ثانیه یک درخشش کوتاه حرکت می‌کند.
- آمار کیفیت چله پنج سطح دارد: خیلی ضعیف، ضعیف، متوسط، خوب و عالی. داده‌های قدیمی چهار سطح قبلی همچنان خوانده می‌شوند؛ سطح «خیلی ضعیف» گزینهٔ تازه است.
- در صفحهٔ خانه، حلقهٔ پیشرفت ۴۰روزه کمی بزرگ‌تر و در سمت چپ نمودار پنج‌ستونی قرار گرفته است.
- در صفحهٔ جزئیات چله نیز حلقهٔ روزهای سپری‌شده در سمت چپ و نمودار کیفیت در سمت راست هماهنگ شده‌اند.
- حلقهٔ پیشرفت هر عادت از تعداد خانه‌های ثبت‌شدهٔ همان عادت از ۴۰۰ خانه محاسبه می‌شود و هنگام ثبت خانه به‌روز می‌شود.
- پنج پوستهٔ کامل، پوستهٔ پیش‌فرض «زمرد شاهانه» و تنظیم پوستهٔ دلخواه نسخهٔ قبلی حفظ شده‌اند.

ساخت APK با GitHub Actions:
۱) ZIP را استخراج کن و محتویات پوشهٔ QadamYar_V50 را در ریشهٔ مخزن GitHub قرار بده.
۲) به شاخهٔ main ارسال کن یا workflow با نام Build QadamYar V50 APK را از تب Actions اجرا کن.
۳) پس از موفقیت، artifact با نام QadamYar-V50-debug-apk را دریافت کن.

ساخت محلی: JDK 17، Android SDK Platform 36 و Gradle 8.11.1 لازم است؛ سپس در Android Studio پروژه را Sync و Build APK اجرا کن.

وضعیت آزمون: ساختار ZIP، فایل منبع، تصویر هدر و نام منابع بررسی شده‌اند. این محیط Android SDK و Gradle نصب‌شده ندارد؛ بنابراین APK در اینجا کامپایل نشده و موفقیت build نهایی هنوز تأیید نشده است. برای تأیید کامپایل، workflow گیت‌هاب یا Android Studio باید اجرا شود.
