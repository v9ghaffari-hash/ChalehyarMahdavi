قدم یار — نسخهٔ ۴۹

این پروژه سورس کامل اپلیکیشن اندروید «قدم یار» بر پایهٔ Kotlin و Jetpack Compose است.
شناسهٔ برنامه: ir.chillehyar.qadamyar.v49
نسخه: 49.0-qadam-yar (versionCode=49)

این نسخه از V48 منشعب شده و با شناسهٔ بستهٔ مستقل نصب می‌شود؛ بنابراین نسخهٔ قبلی را جایگزین نمی‌کند. داده‌های نسخهٔ قبلی به‌صورت خودکار منتقل نمی‌شوند؛ از پشتیبان‌گیری JSON استفاده کن.

تغییرات V49:
- تصویر جدید هدر خانه با نام home_hero.png جایگزین تصویر قبلی شده است.
- پوستهٔ پیش‌فرض «زمرد شاهانه» حفظ شده و پنج پوستهٔ کامل قبلی باقی مانده‌اند.
- انتخاب پوسته‌ها در بخش کشویی قرار گرفته تا صفحهٔ تنظیمات خلوت‌تر باشد.
- بخش «پوستهٔ دلخواه من» اضافه شده؛ کاربر می‌تواند فام رنگ اصلی، رنگ تأکیدی و رنگ پس‌زمینه را تنظیم و ذخیره کند. انتخاب در اجرای بعدی نیز بازیابی می‌شود.
- نمودار چله در خانه چیدمان حرفه‌ای‌تر دارد: حلقهٔ پیشرفت ۴۰ روز در سمت چپ و نمودار ستونی کیفیت در سمت راست؛ ستون‌ها شامل عالی، خوب، متوسط و ضعیف هستند.
- نشانگر درصد هر عادت به حلقهٔ پیشرفت دایره‌ای تبدیل شده و بر اساس تعداد خانه‌های ثبت‌شده از ۴۰۰ قدم همان عادت به‌روز می‌شود.
- سایر منطق‌ها و داده‌های عادت‌ها، چله‌ها، یادآورها و پشتیبان‌گیری از V48 حفظ شده‌اند.

ساخت APK با GitHub Actions:
۱) ZIP را استخراج کن و محتویات پوشهٔ QadamYar_V48 را در ریشهٔ مخزن GitHub قرار بده.
۲) به شاخهٔ main ارسال کن یا workflow با نام Build QadamYar V49 APK را از تب Actions اجرا کن.
۳) پس از موفقیت، artifact با نام QadamYar-V49-debug-apk را دریافت کن.

ساخت محلی: JDK 17، Android SDK Platform 36 و Gradle 8.11.1 لازم است؛ سپس در Android Studio پروژه را Sync و Build APK اجرا کن.

وضعیت آزمون: ساختار ZIP و وجود فایل‌های منبع بررسی شده است. این محیط Android SDK و Gradle نصب‌شده ندارد؛ بنابراین APK در اینجا کامپایل نشده و موفقیت build نهایی هنوز تأیید نشده است. برای تأیید کامپایل، workflow گیت‌هاب یا Android Studio باید اجرا شود.
