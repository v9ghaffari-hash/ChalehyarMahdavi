قدم یار — نسخه ۴۰
در مسیر یار شدن برای امام زمان (عج)

این پوشه، ریشهٔ تمیز پروژهٔ اندروید است. فایل‌های پروژه در یک نسخه نگهداری شده‌اند؛ فایل‌های موقت، نسخه‌های (1)، خروجی build و فایل‌های استخراج‌شدهٔ قدیمی داخل ZIP نیستند.

ساختار پروژه
- app/ : کد و منابع برنامه
- .github/workflows/build.yml : ساخت خودکار APK در GitHub Actions
- build.gradle و settings.gradle : تنظیمات Gradle
- gradle.properties : تنظیمات ساخت

باز کردن و ساخت در Android Studio
۱) ZIP را در یک پوشهٔ خالی با نام QadamYar_V40 استخراج کن؛ آن را روی پوشهٔ استخراج‌شدهٔ V38 یا V39 باز نکن.
۲) در Android Studio پوشهٔ QadamYar_V40 را به‌عنوان پروژه باز کن.
۳) اجازه بده Gradle Sync انجام شود.
۴) از مسیر Build > Build Bundle(s) / APK(s) > Build APK(s) فایل APK را بساز.

ساخت APK در GitHub
۱) محتویات پوشهٔ QadamYar_V40 را در ریشهٔ یک مخزن خالی GitHub قرار بده؛ خود پوشه را دوباره داخل یک پروژهٔ قدیمی ادغام نکن.
۲) روی شاخهٔ main پوش کن یا از تب Actions، گردش کار Build QadamYar V40 APK را دستی اجرا کن.
۳) پس از موفقیت، artifact با نام QadamYar-V40-debug-apk را از اجرای workflow دریافت کن.

نکات مهم نصب و اطلاعات
- applicationId عمداً همان مقدار نسخهٔ ۳۹ نگه داشته شده است: ir.chillehyar.mahdi.next
- نام SharedPreferences و کلیدهای دادهٔ قبلی عمداً تغییر نکرده‌اند؛ بنابراین کد به همان مخزن دادهٔ نسخهٔ قبلی متصل می‌ماند.
- برای نصب به‌روزرسانی روی نسخهٔ قبلی، امضای APK نیز باید با نسخهٔ نصب‌شده یکسان باشد. اگر امضا متفاوت باشد، اندروید به‌روزرسانی را نمی‌پذیرد؛ پیش از حذف نسخهٔ قبلی، از داخل برنامه خروجی JSON بگیر.
- برای اعلان‌ها، مجوز اعلان اندروید باید فعال باشد. در Android 12 به بعد، برای زمان‌بندی دقیق ممکن است لازم باشد دسترسی «هشدارها و یادآورها» نیز از تنظیمات سیستم فعال شود. محدودیت باتری و حالت مزاحم‌نشدن گوشی هم ممکن است روی صدا اثر بگذارد.

امکانات نسخهٔ ۴۰
- صفحهٔ اصلی با هویت بصری سبز زمردی، کرم و طلایی و بنر مسیر؛ یک جوان رهرو در پیش‌زمینه و نماد مردانهٔ دوردست، بدون نمایش چهره.
- سه عادت پیش‌فرض: قرائت قرآن، نماز اول وقت، ذکر و دعا.
- برای هر عادت ۴۰۰ خانه در ۱۰ لقمهٔ مستقل ۴۰تایی؛ شماره‌ها پیوسته از ۱ تا ۴۰۰ هستند.
- مربع‌های بزرگ‌تر و افقی؛ وضعیت باز/بسته بودن، جای اسکرول عمودی صفحه و جای اسکرول افقی ردیف خانه‌ها ذخیره می‌شود.
- فرم ساخت عادت فقط پس از زدن «ایجاد عادت» باز می‌شود. تاریخ شمسی، لقمهٔ آغازین، نماد، رنگ و سه سطح هدف در همان فرم انتخاب می‌شوند.
- بعد از ساخت، اطلاعات و اهداف زیر عادت به‌شکل فرم طولانی نمایش داده نمی‌شوند؛ یک دکمهٔ کوچک ویرایش برای دسترسی به همهٔ مشخصات وجود دارد.
- نمادهای مذهبی و عمومی، ایموجی دلخواه، انتخاب تصویر از گالری و پالت رنگ، به‌علاوهٔ انتخاب آزاد با تنظیم طیف، شدت و روشنایی برای ساخت رنگ دلخواه.
- چک‌لیست روزانه و چک‌لیست انگیزه قابل ویرایش، افزودن و حذف هستند.
- ابزار «تاکتیک‌های شیطان» با ده عنوان و محل ثبت راه مقابلهٔ شخصی.
- «جدول الف» با ده حوزه و ده ردیف قابل تکمیل.
- بازگشت اندروید در صفحات داخلی به صفحهٔ قبلی برمی‌گردد.
- اعلان آزمایشی، کانال اعلان با صدای زنگ، یادآور روزانه و یادآور اختصاصی عادت‌ها.

وضعیت آزمون
در محیط تهیهٔ این بسته Android SDK و Gradle نصب نبود و دسترسی شبکه برای دریافت آن‌ها هم وجود نداشت؛ بنابراین APK در این محیط کامپایل و روی گوشی اجرا نشده است. فایل‌های Kotlin از نظر خطای نحویِ آشکار بررسی شده‌اند و ساخت XML، فهرست فایل‌ها و سلامت ZIP کنترل می‌شود. تأیید نهایی کامپایل باید از طریق Android Studio یا GitHub Actions انجام شود.
