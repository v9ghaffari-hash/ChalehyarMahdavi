قدم یار — نسخهٔ بومی اندروید ۳۹

این پروژه یک اپلیکیشن Android بومی با Kotlin و Jetpack Compose است.

## هویت و طراحی
- نام برنامه: «قدم یار»
- شعار: «در مسیر یار شدن برای امام زمان (عج)»
- هدر روشن و مینیمال، بنر نمادین مسیر و نور، کارت‌های کرم/سبز/طلایی و نمادهای یکپارچه.

## تغییرات اصلی نسخهٔ ۳۹
- فرم ساخت عادت فقط با زدن «ایجاد عادت» نمایش داده می‌شود.
- زیر هر عادت فقط یک کنترل کوچک ویرایش قرار دارد؛ اطلاعات و سه سطح هدف در حالت عادی نمایش داده نمی‌شوند و فقط در فرم ویرایش قابل تغییرند.
- انتخاب تاریخ با تقویم شمسی و نمایش اعداد فارسی انجام می‌شود. تاریخ‌های میلادی ذخیره‌شده در نسخهٔ قبلی هنگام نمایش به شمسی تبدیل می‌شوند.
- مجموعه‌ای از نمادهای مذهبی و عمومی، ایموجی دلخواه، انتخاب تصویر از گالری و پالت رنگ اضافه شده است.
- تصویر انتخابی برای نماد عادت در حافظهٔ داخلی برنامه ذخیره می‌شود و در کارت عادت، صفحهٔ جزئیات و صفحهٔ خانه نمایش داده می‌شود.
- سه ابزار مستقل اضافه/بازطراحی شده‌اند: «تاکتیک‌های شیطان» با ۱۰ دسته و ثبت راه مقابله و چهار راهکار شخصی؛ «جدول الف» به‌صورت جدول ۱۰ حوزه × ۱۰ ردیف؛ «چک‌لیست انگیزه» با ۱۶ عامل رنگی، تاریخ شمسی و سابقهٔ روزانه.
- جدول ۴۰۰ خانه و کلیدهای قبلی آن حفظ شده‌اند؛ موقعیت اسکرول و وضعیت لقمه‌ها نیز ذخیره می‌شوند.
- سیستم یادآوری بازبینی شده: کانال اعلان جدید با صدای زنگ آلارم و لرزش، تشخیص مجوز اعلان، درخواست دسترسی هشدار دقیق، گیرندهٔ آزمون فوری و زمان‌بندی‌شده، و باززمان‌بندی پس از راه‌اندازی مجدد/تغییر ساعت/منطقهٔ زمانی.
- نمایش وضعیت مجوز اعلان، کانال، هشدار دقیق و بهینه‌سازی باتری به صفحهٔ عیب‌یابی افزوده شده است.
- دکمهٔ برگشت اندروید از صفحات داخلی به صفحهٔ قبلی برمی‌گردد و موقعیت اسکرول هر صفحه حفظ می‌شود.

## سازگاری داده‌ها
- شناسهٔ SharedPreferences و applicationId نسخهٔ پیشین عمداً تغییر نکرده‌اند.
- کلیدهای ثبت خانه‌های ۴۰۰تایی، نام عادت‌ها و یادآورهای قبلی حفظ شده‌اند.
- داده‌های قدیمی جدول انگیزه و جدول الف تا جای ممکن با کلیدهای پیشین خوانده می‌شوند.
- تصاویر سفارشی در فایل‌های داخلی برنامه ذخیره می‌شوند؛ انتقال آن‌ها با فایل پشتیبان JSON جداگانه هنوز پشتیبانی نمی‌شود.

## ساخت APK در GitHub Actions
۱. محتویات پروژه را در ریشهٔ مخزن GitHub بارگذاری کن.
۲. مطمئن شو `.github/workflows/build.yml` در ریشهٔ مخزن قرار دارد.
۳. از تب Actions گردش کار «Build QadamYar V39 APK» را اجرا کن.
۴. پس از موفقیت، فایل `QadamYar-V39-debug-apk` را از بخش Artifacts همان اجرا دریافت کن.

نیازمندی‌های ساخت: JDK 17، Android SDK Platform 36، Build Tools 36.0.0 و Gradle 8.11.1.

## وضعیت آزمون
- ساختار سورس، XML مانیفست و منابع بررسی شدند.
- تبدیل چند تاریخ مرجع میلادی/شمسی به‌صورت مستقل بررسی شد.
- در محیط حاضر Android SDK و Gradle نصب نبود؛ بنابراین APK ساخته یا روی گوشی اجرا نشده است. به‌خصوص صدای اعلان و زمان‌بندی دقیق باید روی گوشی مقصد آزمایش شود.
