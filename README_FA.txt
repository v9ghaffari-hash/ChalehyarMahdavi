قدم یار — نسخه ۴۲
شعار: در مسیر یار شدن برای امام زمان (عج)

این پروژه یک اپلیکیشن بومی اندروید با Kotlin و Jetpack Compose است.

تغییرات اصلی نسخه ۴۲
--------------------
- بازطراحی صفحهٔ خانه بر اساس ترکیب‌بندی تصویر مرجع: تصویر تمام‌عرض، آمار هم‌پوشان، کارت عادت‌ها، دو کارت ابزار، چک‌لیست انگیزه، پیام روز و نوار پایین شناور.
- عنوان «قدم یار» و زیرعنوان روی خود تصویر سربرگ هستند؛ کادر شیشه‌ای متن حذف شده است. نوار وضعیت و نمادهای ساعت/باتری/آنتن در صفحهٔ خانه پنهان می‌شوند.
- تصویر سربرگ نسبت اصلی خود را حفظ می‌کند و با عرض صفحه تطبیق می‌یابد؛ تصویر در گوشی‌های متفاوت کشیده یا فشرده نمی‌شود.
- نوار وضعیت اندروید فقط در صفحهٔ خانه مخفی است؛ در صفحه‌های داخلی دوباره نمایش داده می‌شود. نوار پیمایش پایین گوشی باقی می‌ماند.
- نماد هر عادت در سمت چپ کارت قرار گرفته و دکمهٔ ویرایش از فهرست خانه حذف شده است. لمس کارت وارد صفحهٔ اختصاصی همان عادت می‌شود و ویرایش فقط در همان صفحه در دسترس است.
- تصویر کارت تاکتیک‌های شیطان با تصویر اهریمنی تیره‌تر و واقع‌گرایانه‌تر جایگزین شده و فهرست گزینه‌ها به شکل کارت‌های دو ستونهٔ چندانتخابی باقی مانده است.
- جدول ۴۰۰ قدم، ۱۰ لقمه، انتخاب نماد/تصویر، تاریخ شمسی، رنگ دلخواه، چک‌لیست‌های قابل مدیریت، جدول الف، پیام‌های روزانه و یادآورها در پروژه حفظ شده‌اند.

نصب به‌صورت برنامه‌ای مستقل
--------------------------
- شناسهٔ بستهٔ نسخهٔ ۴۲ برابر ir.chillehyar.qadamyar.v42 است؛ بنابراین در کنار بسته‌های نسخه‌های قبلی نصب می‌شود و آن‌ها را جایگزین نمی‌کند.
- به دلیل جداسازی امنیتی اندروید، اطلاعات نسخهٔ قبلی خودکار وارد این برنامهٔ مستقل نمی‌شوند. برای انتقال اطلاعات، در نسخهٔ قبلی از تنظیمات نسخهٔ پشتیبان بگیر و در نسخهٔ ۴۲ آن را بازیابی کن. فایل‌های تصویری سفارشیِ انتخاب‌شده از گالری ممکن است نیاز به انتخاب دوباره داشته باشند.

ساخت APK با GitHub Actions
--------------------------
۱) تمام محتویات این پوشه را در ریشهٔ یک مخزن خالی GitHub قرار بده.
۲) روی شاخهٔ main پوش کن یا از تب Actions گردش کار Build QadamYar V42 APK را دستی اجرا کن.
۳) پس از پایان موفق، artifact با نام QadamYar-V42-debug-apk را دریافت کن؛ APK داخل آن قرار دارد.

ساخت با Android Studio
----------------------
پروژه را از پوشهٔ QadamYar_V42 باز کن و از مسیر Build > Build Bundle(s) / APK(s) > Build APK(s) خروجی debug بگیر.

محدودیت آزمون این تحویل
----------------------
در محیط آماده‌سازی این فایل، Android SDK و Gradle نصب نبود؛ بنابراین build واقعی APK و اجرای روی گوشی از این محیط تأیید نشده است. فایل workflow برای ساخت APK در GitHub Actions آماده شده است. پس از ساخت، صفحهٔ خانه و مجوزها/یادآورها باید روی گوشی واقعی بررسی شوند.
