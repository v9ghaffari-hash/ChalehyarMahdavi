# مدیریت GitHub و ساخت APK

یک وب‌اپلیکیشن فارسی برای مدیریت مخازن GitHub و اجرای GitHub Actions. این نسخه به شکل **PWA** آماده شده و می‌توان آن را روی گوشی اندروید نصب کرد.

## امکانات

- اتصال به حساب GitHub با Fine-grained Personal Access Token
- مشاهده مخازن و شاخه‌ها
- مشاهده و اجرای GitHub Actions Workflows
- دریافت خروجی APK در صورت ارائه Artifact توسط Workflow
- مشاهده گزارش اجراها، Jobها و خطاها
- مرور، بارگذاری و ویرایش فایل‌های مخزن
- رابط فارسی و راست‌چین
- نصب به‌صورت وب‌اپلیکیشن (PWA) و پوسته آفلاین برای فایل‌های برنامه

## انتشار رایگان روی GitHub Pages

1. یک مخزن جدید در GitHub بساز.
2. تمام فایل‌های این پروژه را در ریشه مخزن قرار بده.
3. وارد **Settings → Pages** شو.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
5. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کن.
6. پس از انتشار، آدرس GitHub Pages را با Chrome در اندروید باز کن و از منوی مرورگر **Install app** یا **Add to Home screen** را بزن.

همچنین Workflow آماده انتشار در مسیر `.github/workflows/pages.yml` قرار داده شده است. برای استفاده از آن، در تنظیمات مخزن به **Settings → Actions → General → Workflow permissions** برو و در صورت نیاز اجازه نوشتن برای Workflowها را فعال کن؛ سپس در **Settings → Pages → Build and deployment**، گزینه **GitHub Actions** را انتخاب کن.

## آیکون برنامه

آیکون ارسالی شما در `icons/icon-192.png` و `icons/icon-512.png` قرار گرفته و در manifest و آیکون صفحه نیز استفاده شده است.

## نکات امنیتی

- توکن GitHub را فقط در دستگاه شخصی خود وارد کن و دسترسی‌های آن را به حداقل لازم محدود کن.
- در نسخه اصلی، گزینه ذخیره توکن در مرورگر ممکن است توکن را بدون رمزنگاری در فضای ذخیره‌سازی مرورگر نگه دارد. بهتر است این گزینه را فقط روی دستگاه مطمئن فعال کنی و پس از استفاده توکن را حذف یا لغو کنی.
- Service Worker فقط فایل‌های پوسته برنامه را کش می‌کند؛ درخواست‌های `api.github.com` عمداً کش نمی‌شوند.
- برای نصب PWA و Service Worker باید برنامه از طریق HTTPS (مانند GitHub Pages) اجرا شود؛ باز کردن مستقیم فایل HTML از حافظه گوشی کافی نیست.
